Local-first AI job search

Job Hunter Agent

A practical recruiting assistant that turns a candidate’s source documents into a working fit profile, scrapes and filters jobs with explainable logic, and keeps a persistent shortlist instead of a throwaway report.

What it already does

Current Working Product

  • Scrapes SEEK with direct job-page capture for better reliability
  • Uses deterministic rules before any LLM call
  • Keeps a persistent local dashboard with saved, hidden, and fresh jobs
  • Tracks review actions such as opened, hidden, and applied
  • Stores local runtime state in plain files for transparency
What is being added now

Profile Import Pipeline

  • Import detailed CV and STAR-style source documents
  • Generate a working profile.json automatically
  • Use admin to refine that profile over time
  • Prepare for tailored CVs and cover letters later
How it works

Simple Product Flow

1. Source Docs In User brings one strong CV, then optionally richer notes like STAR examples.
2. Profile Created The app creates a machine-readable runtime profile used for matching.
3. Jobs Filtered Deterministic rules and optional LLM review shortlist the meaningful roles.
4. Dashboard Persists Good roles stay visible locally even after they fall off the live source.
