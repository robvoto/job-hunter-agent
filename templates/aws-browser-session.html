How to open the session

The browser runs on the EC2 instance under a private display. Use a tunnel from your machine to the AWS host, then open the local noVNC page.

SSH tunnel

ssh -L 7900:127.0.0.1:7900 ubuntu@YOUR_EC2_HOST
If you use AWS Systems Manager Session Manager instead of SSH, forward local port 7900 to the instance's 127.0.0.1:7900 port.

Open noVNC

http://127.0.0.1:7900/vnc.html?autoconnect=1&resize=remote
If the tunnel is active, this page shows the browser running on the EC2 display. Use it only for admin access while SEEK is waiting for human verification.

When SEEK blocks

Keep the browser session open, complete the verification check, then return to the workspace. SEEK will resume once job cards appear.
