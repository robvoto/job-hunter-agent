Global settings

These controls are separate from your normal settings. They are shared, centrally managed values that shape search defaults, limits, scoring, onboarding, and workspace behaviour.

Description Compaction

Controls whether job description boilerplate is stripped before LLM review, and the safety thresholds for that stripping. Which sections to strip is governed by data/knowledge/description_compaction_rules.json.

When enabled, known boilerplate sections (privacy notices, EEO statements, how-to-apply text) are stripped from job descriptions before they are sent to the LLM reviewer.
If the compacted description would be shorter than this, the original is kept unchanged. Prevents stripping so much that the description becomes too short to review reliably.
If compaction would remove more than this fraction of the original text, the original is kept. For example, 0.5 means at least 50% of the original must survive.
