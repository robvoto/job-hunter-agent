JOB HUNTER AGENT - QUICK RUN COMMANDS
=====================================

Open this file anytime when you forget what to run.


CANONICAL COMMAND
-----------------

Default command:
python source_connector.py

This is the one canonical run command for the job-hunter agent.

Use it by default unless you specifically need a testing or rebuild-only workflow.


MAIN COMMANDS
-------------

1. Default run

Command:
python source_connector.py

What it does:
- runs the normal scrape
- uses your normal search settings from `profile.json`
- keeps the quick card gate on
- uses the normal shortlist behavior
- rebuilds the dashboard with the latest normal run

Use this when:
- you want the real shortlist
- you want the dashboard out of test mode
- you want fresh jobs using the current saved profile
- you are unsure what to run and want the safe default


2. Dashboard-only test refresh

Command:
python source_connector.py --rebuild-dashboard --test-dashboard-mode

What it does:
- does NOT scrape SEEK
- does NOT run the LLM
- rebuilds the dashboard from jobs already saved locally
- resets `New To You` for testing
- shows a broader shortlist for testing
- the right panel will say `Test mode ON`

Use this when:
- you want a longer list quickly
- you want to test the dashboard UI
- you do not need fresh jobs


3. Fresh test scrape

Command:
python source_connector.py --test-scrape-mode

What it does:
- does a real scrape
- runs the normal scoring pipeline
- can run LLM review where needed
- uses a wider net for testing
- resets `New To You` for testing
- skips the quick card metadata gate for testing
- shows a broader shortlist for testing
- the right panel will say `Test mode ON`

Use this when:
- you need fresh jobs
- you need fresh LLM-reviewed results
- you want more results than the normal run


4. Reset viewed state only

Command:
python source_connector.py --rebuild-dashboard --reset-new-to-you

What it does:
- does NOT scrape SEEK
- does NOT run the LLM
- rebuilds the dashboard from current saved results
- resets `Viewed / New To You` for display
- does NOT switch the dashboard into test mode

Use this when:
- you want the current dashboard to feel like a first look again
- you want clean feedback on the current results without a new scrape


ADMIN SERVER
------------

Start or restart admin:
python admin_api.py

Use this when:
- you want to open `http://127.0.0.1:8765/admin`
- you want to open `http://127.0.0.1:8765/dashboard`
- you changed admin UI/server code and want the latest behavior


OUTPUT FILE
-----------

Dashboard HTML:
output/dashboard.html

Open this file in a browser after a rebuild or scrape.


WHAT "NEW TO YOU" MEANS
-----------------------

Normal run:
- a job is `New To You` if you have not opened it from the dashboard before

Test dashboard mode / test scrape mode:
- everything is treated as `New To You` for testing

Reset viewed state only:
- current jobs are shown as unseen again, but the dashboard stays in normal mode


WHICH ONE SHOULD I USE?
-----------------------

If you are unsure, always use:
python source_connector.py

This is the canonical command.

Only use the others when you intentionally want a special workflow.

If you want a clean first-look dashboard from current saved results:
python source_connector.py --rebuild-dashboard --reset-new-to-you

If you want to test the dashboard UI without scraping:
python source_connector.py --rebuild-dashboard --test-dashboard-mode

If you need fresh jobs and a wider test run:
python source_connector.py --test-scrape-mode


QUICK NOTES
-----------

- If the right panel says `Test mode ON`, you are looking at a test-mode dashboard.
- Run `python source_connector.py` to get back to a normal dashboard.
- Console logs now show whether a run is `real` or `test`.
- If you save profile changes in admin, the next scrape will use them.
- If admin save feedback does not look right, restart the admin server with `python admin_api.py`.
