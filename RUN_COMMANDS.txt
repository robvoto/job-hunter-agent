JOB HUNTER AGENT - QUICK RUN COMMANDS
=====================================

Open this file anytime when you forget what to run.


PRIMARY COMMANDS
----------------

▶ Normal Manual Refresh:
  python source_connector.py

  Use this for a standard run. It scrapes fresh jobs using your profile
  settings and rebuilds the dashboard. This is the main command you will
  use for manual refreshes.


▶ Automated Agent Run:
  python agent_runner.py

  Use this to run the full agent pipeline: refresh jobs, create a digest,
  and send notifications.
  - Add `--loop` to run it on a daily schedule.
  - Add `--no-notify` to test the digest without sending alerts.


▶ Local Web Server:
  python local_server.py

  Use this to start the web server for the Admin UI and to view the dashboard
  in your browser.
  - Admin: http://127.0.0.1:8765/admin
  - Dashboard: http://127.0.0.1:8765/dashboard


COMMON WORKFLOWS & FLAGS
------------------------

You can combine flags with `python source_connector.py` to create specific workflows.

---

▶ For Fast UI/Dashboard Testing (No Scrape):
  python source_connector.py --rebuild-dashboard

  This is the fastest way to see UI changes. It skips all scraping and
  AI review, and just rebuilds `dashboard.html` from the last saved run.

  Combine with `--test-dashboard-mode` to see more jobs and debug scores:
  python source_connector.py --rebuild-dashboard --test-dashboard-mode

---

▶ For Quick & Cheap Scrape Testing:
  python source_connector.py --test-scrape-mode

  This mode is designed for cheaper and faster feedback during development.
  It does a real scrape, but:
  - Forces the use of a cheaper LLM model (gpt-4o-mini) to save costs.
  - Widens the search to find more roles for testing.
  - Lowers the dashboard score threshold to 35 to show more borderline jobs.
  - Shows raw scores on job cards for easier tuning.

  For a super-fast check, limit it to one page:
  python source_connector.py --test-scrape-mode --max-pages 1

---

▶ Other Useful Flags:

--no-llm
    Skips the AI fit review step entirely, even if an API key is configured.
    Useful for very fast runs when you only want to test the deterministic filters.

--max-pages <number>
    Temporarily overrides the 'Max pages to check' setting from your profile.

--reset-new-to-you
    Resets the 'Viewed' status for all jobs, making the dashboard feel like a
    first look again. Often used with `--rebuild-dashboard`.


QUICK NOTES
-----------

- If the right panel says `Test mode ON`, you are looking at a test-mode dashboard.
- Run `python source_connector.py` to get back to a normal dashboard.
- Console logs now show whether a run is `real` or `test`.
- If you save profile changes in admin, the next scrape will use them.
- If admin save feedback does not look right, restart the local server with `python local_server.py`.
